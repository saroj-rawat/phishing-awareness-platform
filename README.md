# Phishing Awareness Platform

## Project Overview

This project is an educational website developed to raise awareness about phishing attacks. It helps users identify phishing emails, recognize suspicious website links, and follow cybersecurity best practices through interactive learning activities.

## Features

- Awareness Homepage
- Email Threat Analysis
- URL Risk Analyzer
- Security Tips
- Security Awareness Quiz
- Training Completion Report

## Technologies Used

- HTML5
- CSS
- JavaScript
